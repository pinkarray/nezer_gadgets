# Nezer_Gadgets

Minimal Next.js starter for the Nezer_Gadgets website.

## Getting started

1. Install dependencies:

```bash
cd Nezer_Gadgets
npm install
```

2. Run development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Project files

- `package.json`: scripts and deps
- `app/`: Next.js app router (`layout.js`, `page.js`)
- `styles/globals.css`: basic styling

Customize pages and components as needed.
